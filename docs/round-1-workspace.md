# 第一轮工程：让建档到训练更连贯

日期：2026-10-21。本轮为现有项目的增量修改，没有新增生产依赖，也没有更换后端接口或重写答辩、报告模块。

## 用户流程

1. 创建项目先展示名称、类型、简介和目标用户。输入后 500ms 自动保存草稿，也可手动保存；离开时尝试补存，失败则提示。刷新或从首页/“我的项目”继续填写。
2. 展开方案与价值，补齐必填资料后正式保存。草稿允许字段未完成，不参与模型分析；正式项目继续使用原有严格校验。
3. 在“我的项目”按名称或简介搜索，进入编辑或训练。归档仅从日常列表收起，支持恢复，不删除历史会话。
4. 编辑保存时保留旧版资料，在详情页只读展开。已有会话、报告仍使用原来的项目/画像快照；改动资料后，新训练需要匹配新版的画像。
5. 训练准备确认当前资料、来源与首位评委。点击主按钮后，缺匹配画像就先分析，成功后连续创建会话；分析失败不会创建会话，也不会降级为模拟回复。
6. 可原页展开模型配置，关闭时刷新配置状态；保留项目选择。只有确认并点击开始，才发送资料进行分析和训练。
7. 首页展示最新草稿和最多三个已保存会话入口。会话是否结束以进入后的后端状态为准，旧入口不虚称正在训练。

## 数据与失败保护

- `Project` 正式结构不变；`defense-chamber.projects.v1` 的原集合增加可选缺省字段 `revisions`、`archivedIds`。旧格式直接可读，读取不会自动重写。
- 当前项目、旧版本和归档状态同次写入，写后回读确认。项目更新保留 ID 与创建时间，更新时间递增。未确认写入重试不会重复产生版本。
- 项目草稿单独保存在 `defense-chamber.project-drafts.v1`。新建一份，编辑按项目 ID 分开；草稿包含原项目基线，用于防止覆盖其他页面的新修改。
- 同步损坏、版本不兼容、配额与回读异常均明确显示，原记录不自动清除。多页面冲突时保留本页输入并拒绝覆盖较新的记录。
- 项目/版本序列化估算上限 3 MiB，草稿 1 MiB；浏览器总配额与历史归档共享，实际仍可能更早失败。不静默淘汰旧版本。
- 新请求期间禁止重复点击；会话创建失败复用已有画像与原创建请求标识；离开或切换项目后，迟到画像不再创建会话或导航。
- 模型密钥继续仅保存在本机后端；本轮数据结构不包含密钥。

## 实际验证

- `npm run typecheck`：共享类型、后端、Vue 与前端配置类型检查通过。
- `node node_modules/vitest/vitest.mjs run --no-file-parallelism`：38 个文件、351 项测试通过。新增 19 项涵盖草稿恢复、损坏/配额/未确认写入、多页面冲突、版本/历史快照、归档恢复、连续分析创建、防双击、失败重试及迟到响应。
- 组件测试调整后单独执行 `attachments.test.ts`：7 项通过，消除将带路由守卫的表单脱离 RouterView 渲染产生的测试警告。
- `npm run build`：共享包、后端和前端生产构建通过。Rollup 提示 Zod 依赖中的 PURE 注释位置不支持，移除注释继续构建，未造成失败。
- 浏览器隔离来源 `127.0.0.1:5174` 与临时后端 `3101` 实际检查：填写少量资料、保存草稿、刷新恢复、首页和列表草稿入口、补齐创建、先分析后创建会话并显示首问、会话刷新恢复、编辑后旧版查看、新版画像失效、原会话保留旧名称、搜索、归档/恢复、编辑后回训练、原页模型设置。
- 390px 检查项目列表、编辑、准备和内嵌设置；1440px 检查项目列表，所测页面无横向溢出。所测浏览器控制台未捕获 warning/error。
- 流程模型响应为本地固定测试数据，页面横幅与问题均有标记；没有调用真实外部模型，没有读取或修改正式模型配置，没有使用正式 5173 工作区数据。上述结果不证明真实模型提问质量。

## 当前限制与下一轮

- 数据仍以当前浏览器与本机后端为边界，不跨设备同步。清除浏览器数据会失去草稿与本地版本。
- 现有历史归档 JSON 导出不包含本轮独立草稿、版本/归档元数据或附件原文件，不能作为完整工作区备份。
- 草稿冲突或损坏不自动合并、删除或重置；需保留/备份输入后人工核对。当前没有版本回滚和差异对比功能，旧版只读。
- 没有新增环境变量；真实训练沿用系统设置，或后端 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL`，可选 `AI_TIMEOUT_MS`、`AI_RESPONSE_FORMAT`。本轮未做真实模型质量验收。
- 第二轮再做训练偏好、主题推进状态、“不会回答/给我提示”入口，以及把评委建议整理成可追踪的项目改进任务。本轮未实现这些功能，不将其计为完成。
