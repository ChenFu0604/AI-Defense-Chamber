# 训练准备与表单交互优化

2026-10-25，按实际页面反馈进行增量调整。

- “继续已有会话”改为紧凑的单列卡片，以项目名为标题，显示模式、上次保存的状态、时间及回答次数。编号作为次要信息，最多显示五场，提供完整历史入口。
- 最近会话存储兼容旧记录。旧记录没有时间或进度时不补造数据，打开会话后按实际服务端记录更新；列表上的进度不是实时在线状态。
- “配置或检查模型”改为原生模态弹窗，复用原模型列表、连接测试和后端保存。打开才挂载表单，关闭时取消未完成的读取/测试并清除内存中的输入密钥；已保存配置继续生效。
- 配置弹窗不改变所选项目、评委及训练选项，关闭后刷新基础服务状态。没有配置模型时，开始真实训练仍使用同一弹窗，不自动改为模拟模式。
- 创建成功但导航失败时立即刷新会话入口，可通过卡片恢复。
- 项目及设置表单的文字输入框、下拉框和多行文本框补充浅色底与细边界，保持聚焦、错误、禁用及只读状态可辨；聊天输入和单选/勾选控件沿用各自布局。
- 项目建档/编辑顶部采用紧凑工具栏，桌面将标题说明与导入/示例操作并排，草稿状态和材料入口紧随其下；窄屏自然换行，不靠大段空白分组。
- 项目名称和项目类型补齐说明层级，使用共享行与相同控件高度，避免一边有提示文字而输入区上下错位；窄屏继续单列。
- 项目资料复用快照组件，以独立的浅色卡片展示五项原始资料；简介通栏，其余桌面分两列、窄屏单列。按内容自然撑高，保留长文本和换行，历史快照也使用同一展示规则。

本次没有更改模型协议、报告评分或真实 AI 结果。UI/SSR、状态及存储测试不等于实际浏览器实屏验收。
