# 语音答辩基础版

本阶段在现有文字答辩上增加逐轮语音输入和评委问题朗读。语音不另建会话，不改变评委、RAG、引用、历史报告或五维评分的业务规则。

## 使用流程

1. 打开“系统设置 → 语音服务”，配置独立的语音识别（ASR）和语音合成（TTS）服务。
2. 获取预置音色目录，为商业、技术、用户、魔鬼四位评委分别选择声音。目录来自明确标注的官方内置音色配置，不代表已访问服务商验证可用性。
3. 点击试听，后端使用当前填写的 TTS 配置实际合成示例。试听成功仅验证该次播报，不代表语音识别或聊天模型已经验证。
4. 保存到后端。浏览器不会保存或重新读取原始 API 密钥；已有密钥留空保留，更换服务地址需要重新填写。
5. 进入答辩后使用麦克风入口，允许浏览器访问设备，录音完成后转写，核对文字并加入回答草稿，再按原有流程发送。
6. 点击评委消息旁的播放按钮朗读已保存的问题，随时停止。播报失败不影响文字问题，也不重新生成评委回复。

配置保存在本机后端 `apps/server/.data/voice-config.json`，该目录由 Git 忽略。首版没有语音环境变量回退，不会读取或复用聊天、向量服务的密钥。保存配置不自动调用语音服务，不代表连接已经通过测试。

## 接入范围

- ASR 首版使用标准 OpenAI 兼容 `/audio/transcriptions`。只有支持该音频接口的服务可以使用；聊天接口兼容不代表音频兼容，不能直接把任意 Qwen 聊天模型填入识别配置。
- TTS 提供阿里云 Qwen 官方语音接口和 OpenAI 兼容语音接口两种适配。音色必须匹配提供方和所选模型，不同服务的 ID 不能混用。
- 官方目录用于选声，最终发音、延迟、账户权限和可用性仍以实际试听及服务商响应为准。
- 语音识别发送录音给用户配置的识别服务；播报发送对应文字给配置的合成服务。聊天、向量和语音服务的密钥相互独立。

参考：[阿里云非实时语音合成](https://help.aliyun.com/zh/model-studio/non-realtime-tts-user-guide)、[Qwen 音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)、[OpenAI 官方语音合成文档](https://developers.openai.com/api/docs/guides/text-to-speech)。

## 状态与记录

- 录音和转写不等于提交回答；只有用户确认加入草稿并发送后，文字才进入答辩消息及报告。
- 录音期间停止评委播放，避免录入播报声音。关闭录音面板、切换问题/会话、结束或离开页面时释放麦克风，并取消未完成的音频请求。
- 开始录音前先读取本机公开配置，未启用、配置缺失或读取失败时显示设置与重试入口，不先申请麦克风权限。配置检查不调用外部语音模型。
- 录音按实际经过时间计时，并以短片段监控大小；切换到后台标签页时停止采集，返回后仍可继续识别已有录音。
- 过期的识别结果不能写入另一道题或另一会话。识别失败保留本次录音以便重试，文字草稿不被静默覆盖或截断。
- 原始录音不写入 LocalStorage 或答辩历史，不提供历史录音回放；刷新或离开后仅已保存的文字草稿/正式消息可恢复。
- 单次录音最长 120 秒、上传最大 10 MiB，识别文字和原草稿合计最多 4000 字；超限明确提示，不静默截断。
- 浏览器录音通常需要 HTTPS 或 localhost 和麦克风许可。没有设备、不支持录音或权限被拒绝时，可以继续文字答辩。
- 语音请求失败不切换为假转写、假播报或模拟评委结果。

## 当前限制

这是“录音 → 转写核对 → 提交 → 评委追问 → 手动播报”的逐轮模式，不是实时语音通话。当前不包含 WebRTC、VAD、自动交接话轮、边说边转写或打断模型生成。

评分依据仍是用户确认提交的文字。不根据转写文本生成未经测量的语速、停顿、情绪、自信或口语流畅度评分。四评委仍复用现有单模型角色提示词，不宣传并行多 Agent。

实际麦克风、扬声器、中文识别质量和服务商真实音色听感需在用户设备及已配置服务上验收。协议测试使用隔离的固定响应，不能替代这部分验收。
