# 答辩工作台界面调整

## 本轮改动

- 侧栏隐藏滚动条，保留滚动能力；移除“开发指南”导航入口。
- 准备页、答辩页和二次训练页共用四角色选择卡片，显示图标、简介、关注维度和选中状态。原生 radio 支持键盘选择，异步切换期间以服务端确认角色为准。
- 真实模型与模拟演示使用来源卡片，保留明确的调用与模拟说明。
- 会话状态、实际提问数量与已保存回答数合并为状态卡；进度仅代表问题数量，不能视为能力分数或完成率。
- 将请求加载提示放入消息列表，依据真实请求状态显示，不使用虚假计时。首问失败或无问题结束时显示对应提示。
- 单轮预览改为可折叠标题卡片，来源选择和操作按钮放入独立面板；减弱评委双重描边，窄屏使用纵向操作布局。

## 实际验证

- `npm test`：35 个测试文件、324 项测试通过，包含新增的 4 项组件渲染测试。
- `npm run typecheck`：shared、server、web 类型检查通过。
- `npm run build`：后端 TypeScript 与前端生产构建通过；存在两条既有 Zod 注释位置警告，不影响构建。
- 浏览器隔离预览使用临时后端数据和明确标注的固定测试响应，未调用用户模型或读取模型密钥。验证首问、回答追问、失败保留输入及重试、切换评委、结束及刷新恢复。
- 检查桌面布局与 390px 窄屏，角色和来源选择支持点击及键盘；无横向溢出。检查时未发现控制台 warn/error。
- 单轮预览验证展开、收起、来源切换和基于画像启用/禁用操作按钮；本轮未调用单轮真实模型。

## 范围与限制

本轮调整界面与状态反馈，沿用现有 API、会话保存和模型服务。浏览器固定响应仅验证交互，不能证明真实模型质量；测试模板重复的问题仍会被现有去重规则拒绝。
