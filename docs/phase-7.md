# 第七阶段：项目漏洞地图

## 使用入口

- 项目详情 → “查看项目漏洞地图”：`/projects/:id/risks`，读取当前浏览器的真实项目画像。只有主动进入 `?mode=demo` 才读取模拟画像，并展示模拟数据标识。
- 答辩报告 → “查看本场答辩漏洞地图”：`/defense/sessions/:id/risks`，读取服务端会话的画像、逐轮风险及已有评分报告。不需要当前浏览器仍保留对应项目。
- 没有画像、风险或报告时如实显示空状态或缺报告说明。服务读取失败、数据损坏与 ID 无效均显示错误和重试；不会自动改成模拟结果。

## 数据与来源

共享类型和 Zod 契约在 `packages/shared/src/risk-map.ts`。节点包含稳定唯一 ID、名称、描述、等级及等级说明、来源、类别、原始依据、证据缺口、建议和人工核验信息；关联边由独立的 `RiskEdge` 记录两端 ID、关联类型、解释及依据。

四类来源：用户项目资料、用户答辩回答、AI 推测、有证据支持（人工核验）。原文来自用户不代表 AI 风险判断得到证明：画像中 certainty=provided 的节点标为用户项目资料，其他画像风险、逐轮风险与报告发现均保留为 AI 推测。每个节点单独标注原文来源，引用逐字校验由上游和地图投影再次检查。当前没有人工核验工作流，因此自动投影不会产生“有证据支持”的节点；该来源契约必须附原始资料和人工核验记录。

`risk-map-build.ts` 只整理已有风险、证据缺口与报告薄弱点/优先问题，不根据项目名称推测新风险，不新增模型调用。项目、画像、会话、报告必须匹配。相同名称、描述、回答依据的报告薄弱点与优先问题合并，保留两个来源。未定级的缺口和薄弱点默认中级，并明确说明这只是展示等级；优先问题沿用报告处理优先级映射展示，不称为独立风险测量。

当前边仅表示 `shared_evidence`：两项引用同一项目字段或同一条实际用户回答。采用每组共同依据的星状连线，避免密集的全连接。每条边明确解释“共同依据，不代表因果关系”。不按相似标题、关键词或同属一份 AI 文档就连线；无共同原始依据时独立展示，不补造因果链。缺口和改进任务也仅依据共同回答关联。没有直接任务时显示未提供，不自动补造建议。

Zod 检查字段、枚举、长度、来源、节点/边唯一 ID、重复节点对、缺失端点、自连线及关联共同依据；非法数据不会进入 Vue Flow。图数据是现有来源的确定性投影，页面重新读取即可恢复，不单独持久化另一份易过期的图。节点拖动只调整本次页面布局，不写回分析和报告。

## 界面与依赖

新增 `@vue-flow/core` 1.48.2，地图路由和画布按需加载。自定义风险节点、选中样式、详情侧栏/窄屏下方详情、等级筛选、节点清单、可点击关联节点和连线解释。支持拖动节点/画布、缩放按钮、触控缩放、适应画布与原始比例；滚轮保留页面滚动。禁用创建和删除连线，防止视觉操作修改风险关系。宽度变化时重新适配，页面离开清理等待与选择，重新进入重建 Vue Flow 实例。

实现参考 [Vue Flow 官方指南](https://vueflow.dev/guide/)、[节点](https://vueflow.dev/guide/node.html)和[连线](https://vueflow.dev/guide/edge.html)。业务逻辑、来源读取、状态、布局、节点与详情组件分离，没有重写现有项目/报告业务。

## 限制

当前没有 AI 因果推断、人工核验界面、跨会话汇总、图布局持久化或图导出。共同依据只是检查问题之间联系的线索，不代表两项风险必定互相影响或已成立。共享数据结构预留核验来源，但模型和页面都不能自动赋予已验证身份。

## 验证

本阶段新增测试覆盖真实来源投影、去重、引文与建议一致、共同依据连线、禁止装饰关系、来源与人工核验契约、非法 ID/缺字段/重复/悬空边、空图、来源不匹配、模拟隔离、Vue Flow 数据映射、详情实际渲染、筛选、错误重试、切页迟到响应和只读来源读取。浏览器使用独立端口的固定测试样例，不读取用户资料或调用模型。

实际执行：`npm test` 全量 28 个文件、280 项通过（本阶段新增 19 项）；`npm run typecheck`、`npm run build` 和差异空白检查通过。构建保留两条已有 Zod 注释警告。Vue Flow 画布和路由已单独分包加载。

浏览器验收：节点显示与点击详情、关联节点切换、点击连线解释、风险等级筛选、缩放按钮、画布平移、节点拖动、报告/地图页面来回切换后的重新初始化、空数据、读取失败后重试均正常。桌面双栏和窄屏纵向详情均无横向溢出，未见控制台错误或警告。截图中的项目和风险为明确标注的固定测试样例，不是实际模型生成验证。
