# 简洁蓝白样板

日期：2026-10-23。用户反馈 Aero 背景不合适后，在三个方案中选择“简洁蓝白：灰白背景、实心卡片、蓝色主按钮”。本轮按该选择替换共享视觉基础，并先完成首页与答辩页样板，保留业务流程、真实记录、模型配置和存储逻辑。

## 范围与实现

- 背景 `#f6f8fb`，白色实心表面，深灰文字，主操作蓝 `#3766d5`；内容卡约 14px 圆角、按钮约 9px 圆角。
- 移除页面中的天空/草坡/气泡装饰、卡片光斑与按钮光泽层；停止加载 Aero 样式。旧样式和装饰组件文件保留，未删除。
- 统一固定侧栏、简洁顶栏、正文间距、输入、按钮和状态提示。修复旧平板规则隐藏导航文字的问题；手机保留四个主导航、创建项目与系统设置入口。
- 首页改为轻页头、真实继续入口、最近项目列表及三步引导。保留新建、全部项目、训练、历史入口，以及四位评委的提问示例；不填充虚构项目或训练成绩。
- 答辩主栏突出当前问题、反馈与输入；评委、议题和设置保留在辅助栏。保留附件、求助、草稿、重试、结束确认和完整记录入口。
- 雷达图与风险连线使用统一中性蓝配色，服务端渲染默认色与页面 CSS tokens 一致，不改变实际分数或关系数据。
- 保留键盘焦点、禁用状态、风险文字标签、减少动态效果及强制颜色模式。正文、主按钮、提示与角色标签的关键 token 组合通过 4.5:1 对比度检查。

## 关键修改

- `apps/web/src/styles/tokens.css`、`clean-workspace.css`、`main.ts`：共享视觉基础与加载顺序。
- `layouts/WorkspaceLayout.vue`、`views/HomeView.vue`、`components/RecentProjects.vue`：导航与首页结构。
- 各业务视图、卡片与表单：清理旧外观类和装饰 import，保留事件和数据逻辑。
- `components/chart-theme.ts`：图表默认配色。
- `tests/blue-theme.test.ts`、`chart-appearance.test.ts`：导航、真实内容与对比度回归，图表默认色与 tokens 一致性。
- `tests/report-layout.test.ts`：在测试准备阶段预加载真实图表依赖，避免 SSR 首次编译图表占用报告断言的超时预算；未放宽断言和超时。

- 本轮是共享基础与首页/答辩样板；其他页面同步使用新视觉，但保留原布局，仍需逐页视觉验收。
