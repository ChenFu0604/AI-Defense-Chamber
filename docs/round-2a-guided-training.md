# 第二轮 2A：引导式训练与相关 BUG 修复

日期：2026-10-22。本轮按上一轮规划中的第一步 2A 实施，保留已有建档、版本、会话、评分与历史功能；未增加生产依赖。

## 功能

- 训练准备增加“项目梳理/答辩演练”，与“真实模型/模拟演示”分开选择。
- 目标可选整体梳理、讲清项目价值、梳理实现方案、检查用户需求；每个评委继续保持自己的角色职责。
- 新训练可选最多 5/10 题，切换评委产生的问题计入上限，提示不计入。改动选择后需重新确认；已保存设置随会话恢复，二次训练继承原设置。
- 三个求助按钮：没思路、换个说法、暂时没有数据。使用独立模型任务与 Zod 响应校验，返回短提示；不发送尚未提交的回答草稿，不自动填入或提交答案。
- 每题每种成功提示保存一份，可在当前页和历史消息中反复查看。独立记录来源、模型、角色与问题，不混入 user/judge 消息，不抬高回答数或题数。
- 求助失败可重试原请求，或选择继续自己回答；输入保持。取消只停止本地重试，服务端在途请求可能仍会完成。
- 回答后直接显示简短反馈和下一问的关联理由，原文依据仍可展开核对。
- 新训练最后回答单独生成评价，不添加第六/第十一题；评价确认保存后自动结束。评价失败保留同一回答，可重试。
- 报告与历史展示训练设置、求助次数及辅助边界；评分上下文只把实际回答作为回答证据。新产生的最后回答风险纳入漏洞地图，仍标记 AI 推测。

## 修复与兼容性

1. **旧反馈误标最新回答**：新回答正在提交或已失败时，不再把上一份反馈挂在“本轮回答反馈”下；必须核对实际关联回答 ID。旧反馈继续保留在消息中。
2. **最后回答缺反馈**：新 5/10 题训练在结束前评价最后一答；修正按钮与加载文案，避免显示还会生成下一问。旧 30 题会话保留原行为。
3. **训练设置丢失**：设置保存在会话快照里，并进入模型上下文、历史和二次训练；来源模式与训练方式不互相覆盖。
4. **草稿保存失败离开无保护**：存储写后确认失败时展示警告，并在离开/关闭页面时保护有内容的草稿。正常已确认保存的草稿不反复弹窗。
5. **重复求助与并发冲突**：相同请求重放、同题同类成功缓存、请求 ID 冲突检查；与回答、结束共用锁，不在求助期间并发推进同一会话。
6. **旧数据/报告失配**：新增会话字段均可选，不给旧会话自动补字段。没有新训练设置或提示时，旧报告来源指纹保持一致，原报告无需重新生成。

## 验证

- `npm run typecheck`：共享包、后端、Vue 与前端配置类型检查通过。
- `npm run build`：共享包、后端与前端生产构建通过，保留既有 Zod/Rollup PURE 注释警告。
- `node node_modules/vitest/vitest.mjs run --no-file-parallelism`：最终 **39 个文件、371 项测试全部通过**。新增 20 项覆盖训练设置、求助结构/来源/缓存/并发/落盘失败、最后回答与重试、旧报告指纹、前端输入保留/刷新、即时反馈误关联、风险与二次训练设置。
- 开发中的首轮定向测试有两项失败：连续测试回答过于相似，触发既有重复问题校验；未配置场景的测试绕过了配置读取器。已改为不同讨论方向的实际测试输入，并通过独立空配置读取器测试未配置错误，没有降低断言或重复校验，也没有调用真实模型。
- 浏览器在隔离 5174/3101 和临时后端数据目录实际检查了训练目标/长度、三类求助、草稿与提示刷新恢复、失败回答刷新重试、即时反馈、五题自动结束、最后回答反馈、报告和历史读取；390px 下对话/求助区域无横向溢出。
- 验收使用此前专用的“第一轮验收”合成项目，新增独立测试会话；没有修改正式 5173 工作区、模型密钥或用户项目资料。页面横幅和响应明确标注固定测试数据。没有调用外部真实模型，不能把固定响应视为引导效果验证。

## 限制与下一步

- 真实模式的提示、反馈与报告已走统一 AI 客户端，但实际措辞、相关性和是否有用仍需要配置真实模型后验证。自动校验不能证明语义正确。
- 模拟提示和反馈为固定模板，不理解实际回答，不生成真实评分。隔离验收环境还包含固定评分模板，仅供流程测试。
- 求助基于当前问题、项目字段和有限历史，当前不重新解析附件或执行外部检索；最终回答评价继续支持当前回答/项目附件材料。
- 提示失败或未能落盘后重试可能再次调用模型；成功缓存只防止成功记录被重复生成。当前仍为单进程本地文件锁。
- 本轮未实现 2B 议题状态/语义去重、改进任务跟踪、新版项目继承旧训练重点、未评估维度评分处理，以及完整工作区备份。
- 无新增环境变量；沿用系统设置或后端 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL`，以及可选超时和输出格式配置。
