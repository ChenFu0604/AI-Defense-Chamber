# Frutiger Aero 全局重构

日期：2026-10-23。根据用户最新风格要求，本轮最终采用单一明亮的 Frutiger Aero 界面，替代本轮早期的方框蓝白/深浅双主题方案。增量重构前端外观与页面结构，保留现有 API、存储、真实模型调用和业务数据。

## 风格取舍

用户提供的规则内部有冲突：一方面要求玻璃面板、按压缩放，另一方面禁止把玻璃当默认外观、禁止弹簧缓动。本轮采用有明确用途的主要玻璃表面，内部内容改为分区和列表，避免玻璃卡片层层嵌套；按压缩放至 95%，使用 ease-out，没有 bounce/elastic 缓动。

最新禁止深色背景、等宽字体和尖角的要求优先于此前双主题、等宽数字、方框按钮的建议。本轮尚未提交的主题切换组件及状态代码已回收，原有项目数据不受影响。

## 实际实现

- 天空蓝渐变、云朵、泡泡和自然草坡装饰。装饰不可聚焦、不可点击，并明确 `aria-hidden`。
- 主要面板使用半透明白色、白色细边、大圆角、强模糊和柔和光影。`AeroDecor` 为按钮/卡片提供实际的上半部光泽 div；卡片另有绿色与天空蓝色两个柔化光斑。
- 胶囊按钮、主次区分、悬停水色光晕、95% 按压反馈。可浏览的项目/评委卡片浮起；输入区和长表单保持稳定。
- 使用 Segoe UI/PingFang/微软雅黑等无衬线字体，移除 Inter、等宽字体和重复的小型英文装饰标题。正文限制为约 72ch，数值仍可使用 `tabular-nums`，未使用等宽字体。
- 输入、按钮和可聚焦元素包含对应风格的焦点规则，天空背景上使用 sky-300 外环与 sky-500 间隔。支持 `prefers-reduced-motion` 与强制颜色模式。
- 使用可复用 `StatusNotice` 组织等待、保存、警告和错误，让提示与对应操作相邻；字段错误仍保留在字段旁。
- 答辩等待计时嵌入评委活动面板，取消单独漂浮的等待文字。报告生成只展示一张等待面板，不叠加重复标题或嵌套实时播报。计时对读屏隐藏，每秒变化不反复播报，慢响应时提示可恢复操作。
- 新收到的完整消息柔和显现，约 240ms 淡入/轻微模糊消退；拖放反馈约 150ms，穿过上传区子元素不会闪烁。

## 顺带修复

- 首页统计包含归档项目、全部归档时缺少空状态。
- 详情加侧栏后画像仍三列，文字过窄。
- 只有最后一答评价时，报告仍提示没有回答分析。
- 旧移动端规则隐藏历史入口和创建项目文字。
- 通用按钮样式挤动附件删除按钮；恢复右上角定位与固定尺寸。
- 未选中的模式出现实心标记；仅给选中模式填色。
- 装饰层被旧内容选择器影响；隔离 margin、display 和布局属性。

## 关键修改位置

- `apps/web/src/styles/tokens.css`：统一天空/玻璃/文本/图表语义变量。
- `styles/aero.css`、`aero-shell.css`：风格、交互、状态、外壳和移动适配。
- 原模块样式：统一变量、圆角、字体；新增布局样式组织项目、答辩及其他页面。
- `components/ui/{AeroDecor,StatusNotice,AppButton,RequestWait}.vue`：共享视觉与状态组件。
- `layouts/WorkspaceLayout.vue`、全部业务视图及卡片/表单组件：导航、布局与状态归属。
- 报告/风险图组件：明亮图表配色、原始数据保留、减少动效与监听清理。
- `blue-theme.test.ts`、`chart-appearance.test.ts`、`report-layout.test.ts`、`status-presentation.test.ts` 与 `session-ux.test.ts`：对比度、导航、图表、引用与状态回归。

生产 token 的正文/辅助文字在最深天空上，以及主要玻璃合成背景上的角色/语义文字，均按 AA 文本 4.5:1 门槛验证；这不是完整 WCAG 验收。

本轮浏览器工具拒绝访问本地页面，没有使用替代通道绕过。因此没有宣称桌面/手机实际渲染、点击、动画观感或控制台验收通过；后续仍需真实浏览器视觉验收，尤其是长内容、窄屏表单和风险地图。

接口仍是普通 JSON 整段返回。柔和显现仅在完整内容到达后播放，**没有实现 SSE 或逐 token 流式输出**。本轮未调用真实模型，也没有新增假评分、假追问或自动生成历史报告。

系统仍是本机单用户工作区，浏览器来源隔离、备份范围与之前一致；没有引入账号、云数据库、生产部署或数据迁移。
