## 安装记录与已知限制

- 默认全局 npm 缓存目录受权限限制，已通过项目 `.npmrc` 将缓存放在被忽略的 `.npm-cache`。
- 初次官方源元数据下载较慢，实际安装使用了 npm 镜像 `registry.npmmirror.com`，锁文件记录了包地址及完整性信息。
- 干净重装使用本机缓存完成；尚未在另一台电脑测试首次联网安装耗时。
- Vite 构建有两条 Zod 依赖注释位置警告，构建工具会移除无法识别的注释；构建退出码为 0，产物预览已通过。
- 当前没有 AI 模型调用、项目创建、训练、报告、风险地图或本地记录存储。
- 健康检查只代表基础 API 可用。前端角色问题为静态示例，核心装置为 CSS 概念图。
- shadcn-vue、ECharts、Vue Flow、OpenAI SDK 和 Vue Test Utils 尚未引入，在使用它们的阶段接入。
